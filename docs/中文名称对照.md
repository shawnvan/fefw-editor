# 中文名称对照

本表记录部分程序采用的人物和道具名称，未覆盖全部内置映射。四位主角参考任天堂繁体中文介绍并转换为简体；其他人物采用攻略站对照名，道具名称参考中文攻略资料。攻略名称不保证与官方简体版完全一致；部分神将道具和常见武器为字面暂译，待核对。未列出的名称保留原文。

来源优先级（人物译名两体系并存，按此取舍）：
1. 官方媒体资料：任天堂繁中介绍（四位主角）、新浪官方角色介绍与游民星空全角色名单（媞雅拉、皮特鲁、杨界、伊修玛尔、迪雅各、绯亚娜、诺克裘拉等，即 unicorncamp 采用的体系）；
2. LPegasus `name-aliases.json` 的 canonical（部分人物采用另一民间体系：蒂亚拉、彼得、法比奥等，列为其别名时以官方媒体系为准）；
3. 其余为音译暂译（独特武器、未列名配角），待官方简中文本核对。
